# Eclaire

**Private, self-hosted AI for your data.** Eclaire captures and understands your notes, documents, photos, bookmarks, media, mail and files, whether they are imported or linked where they already live. It runs AI agents that act on them, using local models by default. It is built for individuals, families and small teams.

> **Eclaire 1.0 is being rebuilt from the ground up.** This branch currently contains the product requirements and design documents; code will land as development progresses. Releases will be versioned from `1.0.0-alpha`.

## Coming from Eclaire 0.x?

Eclaire 1.0 does not upgrade 0.x installations:

1. Start a new instance.
2. Re-import your content. Your 0.x originals are plain files under your 0.x `data/` directory, and 1.0's folder import can bring them back.

Tags, notes metadata and conversations from 0.x are not carried over.
